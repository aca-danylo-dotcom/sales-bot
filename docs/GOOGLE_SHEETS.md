# Подключение Google Sheets (через Apps Script)

Бот выгружает магазин в Google-таблицу двумя листами:

- **«Заказы»** — по строке на заказ: дата, статус, покупатель с телефоном и
  адресом, состав, сумма, накладная, менеджер и заметка.
- **«Остатки»** — весь склад по вариантам: товар, размер, цвет, остаток, цена,
  на витрине он или скрыт.

Синхронизация **односторонняя**: бот перезаписывает оба листа целиком каждые
10 минут и один раз при старте. Править таблицу вручную бессмысленно —
изменения затрутся при следующей выгрузке. Остатки правятся в веб-CRM
(страница «Склад»), заказы — в карточке заказа.

Google Cloud, сервис-аккаунты и файлы-ключи **не нужны** — вместо них внутри
самой таблицы работает маленький скрипт (Apps Script), опубликованный как
веб-приложение. Бот шлёт ему данные, скрипт раскладывает их по листам.

Пока `SHEETS_WEBHOOK_URL` и `SHEETS_WEBHOOK_TOKEN` в `.env` пустые, бот работает
как обычно, а в лог пишет, что выгрузка отключена. Чтобы включить — выполните
шаги ниже (5–10 минут, один раз).

> **Кто увидит данные.** В таблице лежат телефоны и адреса покупателей. Доступ к
> ней раздаётся обычными правами Google — не открывайте её «по ссылке всем».

## Шаг 1. Придумайте секретный токен

Это любая длинная случайная строка (например, 20+ символов букв и цифр). Она —
общий пароль между ботом и скриптом, чтобы данные в таблицу мог слать только ваш
бот. Придумайте один раз и держите под рукой — понадобится в шагах 2 и 4.

## Шаг 2. Создайте таблицу и скрипт

1. Создайте новую Google-таблицу на <https://sheets.google.com/> (название
   любое — на работу не влияет). Листы «Заказы» и «Остатки» создавать вручную
   **не нужно**, скрипт добавит их сам.
2. В таблице меню **Расширения → Apps Script** (Extensions → Apps Script).
3. Удалите весь текст в редакторе и вставьте скрипт ниже. **В первой строке**
   замените `ВАШ_ТОКЕН` на строку из шага 1 (в кавычках).

```javascript
const TOKEN = "ВАШ_ТОКЕН";

function doPost(e) {
  try {
    const data = JSON.parse(e.postData.contents);
    if (data.token !== TOKEN) {
      return json({ ok: false, error: "bad token" });
    }
    const ss = SpreadsheetApp.getActiveSpreadsheet();
    // Пишем только те листы, что прислал бот.
    if (data.orders) writeSheet(ss, data.orders);
    if (data.stock) writeSheet(ss, data.stock);
    return json({ ok: true });
  } catch (err) {
    return json({ ok: false, error: String(err) });
  }
}

function writeSheet(ss, block) {
  let sheet = ss.getSheetByName(block.sheet);
  if (!sheet) sheet = ss.insertSheet(block.sheet);
  sheet.clearContents();
  const values = [block.header].concat(block.rows);
  sheet.getRange(1, 1, values.length, block.header.length).setValues(values);
  sheet.setFrozenRows(1);
}

function json(obj) {
  return ContentService.createTextOutput(JSON.stringify(obj)).setMimeType(
    ContentService.MimeType.JSON,
  );
}
```

4. Нажмите **Сохранить** (иконка дискеты).

### Если таблица уже есть (например, от другого бота)

Скрипт можно не создавать с нуля, а дописать в существующий: магазин пишет
только свои листы и чужие не трогает. В `doPost` добавьте две строки —

```javascript
    if (data.orders) writeSheet(ss, data.orders);
    if (data.stock) writeSheet(ss, data.stock);
```

— и **обязательно переразверните** (см. врезку в конце). Без этих строк старый
скрипт просто не увидит присланные блоки: ответит `{"ok": true}`, а листы не
появятся — со стороны бота выгрузка при этом выглядит успешной.

Токен и URL остаются общими: в `.env` магазина пишутся те же значения, что у
соседнего бота. Минус один — права в Google даются на всю таблицу целиком, так
что доступ к заказам магазина открывает и чужие листы.

## Шаг 3. Опубликуйте как веб-приложение

1. В редакторе скрипта справа вверху **Развернуть → Новое развёртывание**
   (Deploy → New deployment).
2. Шестерёнка **Выберите тип → Веб-приложение** (Web app).
3. Настройки:
   - **Описание** — любое (например, `sales-bot`).
   - **Запуск от имени** (Execute as): **Я** (Me).
   - **У кого есть доступ** (Who has access): **Все** (Anyone).
     > Это безопасно: запись закрыта вашим токеном, без него скрипт отвечает
     > `bad token` и ничего не пишет. Саму таблицу «Все» при этом не видят.
4. **Развернуть**. Google попросит **авторизацию** — разрешите доступ своему же
   аккаунту (экран «Google не проверил приложение» → **Дополнительно → Перейти
   к … (небезопасно)** → **Разрешить**; это ваш собственный скрипт).
5. Скопируйте **URL веб-приложения** — длинная ссылка, заканчивается на `/exec`.

## Шаг 4. Пропишите в `.env`

```
SHEETS_WEBHOOK_URL=https://script.google.com/macros/s/…/exec   # URL из шага 3.5
SHEETS_WEBHOOK_TOKEN=…ваш_токен…                                # строка из шага 1
```

Оба значения должны быть заданы — если хоть одно пустое, выгрузка выключена.

## Шаг 5. Проверка

1. Запустите бота. В логе при старте должно появиться:
   `Google Sheets: выгружено заказов — N, строк склада — M.`
2. Обновите таблицу — появятся листы «Заказы» и «Остатки» с данными.

## Если не работает — смотрите лог

| Сообщение в логе                          | Причина и что делать                                                                                          |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `SHEETS_WEBHOOK_URL/TOKEN не заданы`      | Одно из значений в `.env` пустое (шаг 4).                                                                     |
| `скрипт вернул ошибку … неверный … TOKEN` | Токен в `.env` ≠ токену в скрипте (`const TOKEN`). Должны совпадать буква-в-букву.                            |
| `скрипт ответил HTTP 4xx/5xx`             | URL не тот или заканчивается не на `/exec`; либо веб-приложение не опубликовано / снято с публикации (шаг 3). |
| `сеть/HTTP ошибка`                        | Нет интернета или Google недоступен — само пройдёт к следующему прогону.                                      |
| в логе всё хорошо, но листов нет          | В скрипте нет строк `if (data.orders) …` / `if (data.stock) …` — либо они есть, но не переразвёрнуты.         |

> При изменении скрипта нужно **заново развернуть**: **Развернуть → Управление
> развёртываниями → карандаш → Версия: Новая → Развернуть**. URL при этом
> сохраняется. Если создать _новое_ развёртывание — URL сменится, обновите `.env`.

## Что в каких колонках

**«Заказы»** — № · Оформлен · Статус · Клиент · Телефон · Город · Отделение ·
Состав · Позиций · Сумма · ТТН · Менеджер · Комментарий · Заметка · Оплатил ·
Подтверждён · Отправлен · Канал · Telegram ID.
Свежие заказы сверху. «Состав» — все позиции в одной ячейке, по строке на товар.
«Заметка» — внутренняя, клиент её не видит.

**«Остатки»** — Товар · Категория · Размер · Цвет · Остаток · Цена ·
На витрине · Артикул товара · Артикул варианта · ID товара · ID варианта.
Скрытые товары тоже здесь: склад — это то, что лежит на полке, а колонка
«На витрине» говорит, показывают его клиенту или нет.

Колонки задаются в `services/sheets.py` (`ORDERS_HEADER`, `STOCK_HEADER`) —
чтобы добавить свою, скрипт переразвёртывать не нужно.

## Настройки в `.env`

```
SHEETS_WEBHOOK_URL=      # URL веб-приложения Apps Script (…/exec)
SHEETS_WEBHOOK_TOKEN=    # общий секрет: тот же, что const TOKEN в скрипте
```
